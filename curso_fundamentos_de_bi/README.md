# Fundamentos de BI (curso 1)

Este primeiro curso foi dedicado ao contato inicial com o Power BI, apresentando conceitos fundamentais de Business Intelligence (BI), visualização de dados e construção de relatórios.

Ao longo do curso, foram desenvolvidos dois relatórios simples, utilizando diferentes fontes de dados. A partir deles, foram explorados conceitos relacionados à importação e análise de datasets externos, além dos primeiros passos na construção de visualizações no Power BI.

### Relatório Financials

O primeiro relatório desenvolvido foi o report_powerbi_sample_financial.pbix, utilizando o dataset Financials, disponibilizado como exemplo pelo próprio Power BI.

O relatório foi utilizado para introduzir conceitos de visualização e exploração de dados na ferramenta.

Abaixo, é apresentada uma das páginas do relatório apenas para ilustrar o resultado desenvolvido. O arquivo .pbix está disponível neste repositório para visualização do relatório completo e de todas as suas páginas.

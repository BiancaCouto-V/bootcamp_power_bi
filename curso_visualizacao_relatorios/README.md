# Visualização de Dados e Relatórios com Power BI

Este módulo foi dedicado ao desenvolvimento de relatórios e dashboards no Power BI, com foco na utilização de diferentes recursos de visualização para representar e analisar dados de forma clara e interativa.

Foram abordados conceitos relacionados à criação e utilização de visuais, definição de KPIs e métricas, construção de dashboards interativos e organização de relatórios voltados à análise de informações de negócio.

Ao longo do módulo, também foram desenvolvidos relatórios práticos, incluindo um relatório gerencial de vendas.

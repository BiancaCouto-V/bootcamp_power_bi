# Bootcamp Power BI

Repositório dos projetos desenvolvidos durante o Bootcamp Santander – Power BI, reunindo práticas de Business Intelligence, modelagem de dados, transformação de dados, SQL, DAX e visualização de informações.

## Sobre o projeto

Este repositório documenta minha jornada de aprendizado ao longo do bootcamp, desde os fundamentos de Business Intelligence até a construção de relatórios e dashboards utilizando dados estruturados.

Os projetos foram desenvolvidos de forma progressiva, passando por diferentes etapas do processo de desenvolvimento de uma solução de BI:

**Fundamentos de BI → Preparação e modelagem dos dados → Análise → Visualização e criação de dashboards**

## Conteúdo do repositório

### [01. Fundamentos de BI](./curso_fundamentos_de_bi/)

Introdução aos principais conceitos de Business Intelligence, análise de dados e utilização de informações para apoio à tomada de decisão.

### [02. Modelagem de Dados](./curso_modelagem_de_dados/)

Práticas relacionadas à estruturação e modelagem dos dados para utilização em soluções de BI, incluindo conceitos de modelagem dimensional e relacionamentos entre tabelas.

### [03. Visualização de Relatórios](./curso_visualizacao_relatorios/)

Desenvolvimento de relatórios e dashboards no Power BI, com aplicação de conceitos de visualização de dados, indicadores e análise das informações.

## Projeto final — Chinook

O projeto final do bootcamp utiliza a base de dados **Chinook**, originalmente estruturada como um banco de dados relacional.

A partir dos dados disponíveis em PostgreSQL, foi desenvolvido um modelo de dados para análise no Power BI, passando pelas etapas de preparação, transformação, modelagem e criação das visualizações.

### Principais etapas

- Extração dos dados a partir do PostgreSQL
- Tratamento e transformação dos dados
- Construção do modelo dimensional
- Definição de tabelas fato e dimensão
- Criação de medidas utilizando DAX
- Desenvolvimento de dashboards interativos
- Análise de vendas e produtos

### Tecnologias utilizadas

**Power BI · Power Query · DAX · SQL · PostgreSQL · pgAdmin 4**
